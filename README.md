# Aarzoo Wedding Atelier

Aarzoo Theme Assets — a workspace project for generating illustration and artwork assets (wax seals, backdrops, textures, portrait illustrations) for the Aarzoo wedding-invitation themes. This is an asset-generation sandbox, not a working app: start with a single blank page.

This project was built with [Lovable](https://lovable.dev).
